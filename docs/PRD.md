# PawBudget 毛球账本 v0.1 PRD

## 1. 产品定位

面向猫狗等家庭宠物用户的轻量消费管理工具，核心不是“记账本身”，而是把消费、库存、衣橱和可分享账单串成一个有 IP 温度的宠物生活工具。

产品原则：**帮你算清楚，不替你花钱。**

## 2. MVP 用户任务

1. 3 秒内记录一笔宠物消费。
2. 打开首页即可知道今日、本月、今年花费。
3. 查看猫粮、猫砂、罐头等还能用几天。
4. 查看宠物衣服的单次穿着成本。
5. 查看年度消费结构，并形成可分享内容。

## 3. 页面结构

底部导航：
- 首页
- 记账
- 库存
- 衣橱
- 账单

## 4. 消费分类

- 食物
- 日用
- 衣服
- 玩具
- 洗护美容
- 健康
- 大件 / 服务

## 5. 首页

展示：宠物档案、今日消费、本月消费、年度累计、关键库存、本月消费分布、墨团点评、快捷入口。

## 6. 消费记录

字段：金额、商品、分类、日期、备注。

v0.1：新增 + 列表 + 分类筛选。  
v0.2：编辑 / 删除 / 搜索 / 商家 / 品牌。

## 7. 库存

v0.1 字段：名称、剩余天数、完整周期。  
v0.2：购买量、剩余量、单位、日均消耗、预计用完时间、补货阈值。

## 8. 衣橱

字段：名称、价格、穿着次数、展示图标。  
核心指标：`单次穿着成本 = 价格 / 穿着次数`。

## 9. 年度账单

展示年度总消费、平均每天消费、分类排行与墨团点评。v0.2 输出 3:4 分享长图。

## 10. 商业化边界

未来品牌合作必须明确标注“品牌合作 / Sponsored”。品牌投放不得修改用户真实账本数据或伪装成客观排名。
