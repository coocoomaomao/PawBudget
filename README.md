# 🐈‍⬛ PawBudget 毛球账本

**记录一只宠物，从吃饭到变漂亮，到底花了多少钱。**

PawBudget 是「喵造实验室 007」：一个面向养宠人的本地优先消费账本，包含消费记录、库存提醒、宠物衣橱和年度账单。

> 产品原则：**帮你算清楚，不替你花钱。**

## ✨ v0.1.4

- 宠物首页仪表盘
- 今日 / 本月 / 年度消费统计
- 消费分类：食物、日用、衣服、玩具、洗护美容、健康、大件/服务
- 本月消费分布
- 记一笔消费
- 库存剩余天数与补货提醒
- 宠物衣橱与「单次穿着成本」
- 年度账单
- **一键生成 3:4 年度账单 PNG 分享图**
- 消费记录支持编辑 / 删除
- 宠物档案可修改：名字、年龄、体重、一句话介绍
- 库存根据「剩余量 ÷ 每日消耗」自动计算还能用几天
- 墨团消费点评
- 本地存储，不需要账号
- **安全演示模式**：进入演示前自动备份真实账本，退出后恢复
- **墨团演示模式**：方便 GitHub Demo、小红书截图与录屏
- 库存支持 **补货记录**，可同步把补货花费记入消费账本
- 衣橱支持 **穿着记录**，“今天穿了”会自动降低单次穿着成本
- 完整账本支持 **JSON 导出 / 导入**
- 消费记录支持 **CSV 导出**
- 年度分享图升级：年度总消费、日均、分类排行、最贵单次穿搭、最紧急库存一起生成 3:4 海报
- **宠物头像上传**：照片自动居中裁切、压缩后仅保存在当前设备
- 首页、年度账单与 3:4 分享海报优先展示毛孩子真实头像
- 未上传头像时继续使用墨团默认形象
- **物品照片（可选）**：消费记录、库存、宠物衣橱都可以上传照片
- 图片会在浏览器端压缩后保存在 IndexedDB，不上传服务器
- 消费记录显示商品缩略图，库存显示物品图，衣橱优先展示真实穿搭照片
- 完整 JSON 备份会同时打包物品照片，导入时一起恢复

## 🚀 直接运行

这是一个零依赖的移动端优先 Web App。

最简单：直接打开 `index.html`。

推荐本地服务器：

```bash
python -m http.server 8000
```

然后打开：

```text
http://localhost:8000
```

## 🌿 两个版本

- `main`：真实使用版。首次打开为空白账本，适合正式用户。
- `xiaohongshu-demo`：展示版。首次打开即加载墨团演示数据，适合截图、录屏和 GitHub Pages 展示。

两个版本都可以用右上角 **「演示」** 按钮切换数据状态。

## 📱 小红书展示模式

右上角点击 **「演示」**，可在：

- 墨团完整演示数据
- 空白真实账本

之间切换。

演示模式内置消费、库存、衣橱数据，可直接用于产品截图与录屏。

## 🔒 数据与隐私

v0.1.4 使用浏览器 `localStorage` + `IndexedDB` 保存数据：

- 不需要登录
- 不上传宠物消费数据
- 清除浏览器站点数据会同时清除账本，请谨慎操作
- 宠物头像会压缩后作为本地数据保存，不上传服务器
- 物品照片保存到浏览器 IndexedDB，默认不上传、也不是必填项
- 完整 JSON 备份会包含头像数据，换设备时可一起恢复

## 🖥️ Windows 桌面版

PawBudget 同时提供 Windows 桌面安装版。桌面版使用 Electron 封装同一套本地优先应用：

- 双击安装即可使用
- 创建桌面与开始菜单快捷方式
- 账本、头像与物品照片仍只保存在用户自己的电脑
- 不要求登录
- 卸载应用默认不会主动删除账本数据
- Windows 安装包通过 GitHub Actions 自动构建

本地开发：

```bash
npm install
npm start
```

构建 Windows 安装包：

```bash
npm run dist:win
```

> Early Access 安装包目前未做商业代码签名。部分 Windows 电脑首次运行时可能出现 SmartScreen 提示；正式商业发布建议配置代码签名证书。
